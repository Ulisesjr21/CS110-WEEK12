5 · Introduction to Unity

The professor gave a detailed introduction to Unity and showed how to start a third-person project, where the camera views the character from behind. Unity’s Scene view is where you arrange objects, while the Game view shows what the player sees through the camera. The Hierarchy lists the objects in the scene, and the Inspector lets you adjust their settings. Starting with a third-person project can help me learn how the player and camera work together. I could use this as a starting point for my game. How can I add obstacles and a goal to turn the third-person project into a playable game? and do I have to add a c# code to everything I edit.

6 · Import a custom player

I learned how to add a custom character to Unity. Details to pay attention to include importing the character model, adjusting its size and position, and setting up animations so it can move correctly. A custom character can help my game match the style I want. I would test its movement and animations to make sure it works in the scene. How can I fix a character that moves but does not play its walking animation?
